OMX Control Panel 설치

내 우분투 PC에 로봇팔과 카메라를 연결하고, 학습과 AI 추론은 GPU 노트북에 맡기는 제어판입니다. 아래 순서대로 한 번만 설치하면 바탕화면 아이콘으로 바로 씁니다.

우분투 22.04 / 24.04약 1시간 (대부분 자동)설치 파일: install_control.sh

이렇게 동작합니다

내 제어 PC
  • 리더암·팔로워암·카메라 연결
  • 텔레옵, 데이터 녹화, 평가 실행
  • 안전 시작·정지, 비상 정지
Tailscale
+ SSH
GPU 노트북 (team16-PC)
  • 모델 학습
  • AI 추론 서버 (평가 중 동작 계산)
  • 팀 공유 데이터·모델 보관

녹화한 데이터는 끝나면 GPU 노트북 공유 폴더로 자동으로 올라갑니다. 다른 사람이 만든 같은 이름의 데이터는 덮어쓰지 않습니다.

시작 전에 준비할 것

  • 우분투 PC와 인터넷 연결 (USB 포트가 많을수록 좋습니다)
  • GPU 노트북 계정 이름과 비밀번호. 없으면 관리자에게 요청하세요.
  • Tailscale 팀 초대. 관리자가 보낸 초대 메일로 팀 Tailscale에 들어갈 수 있어야 합니다.
  • 내 PC의 sudo 비밀번호 (패키지·장치 규칙 설치에 필요)
  • 로봇 세트(리더·팔로워, 전원 어댑터)와 카메라. 설치가 끝난 뒤 연결해도 됩니다.

설치 순서

설치 파일 받기

터미널(Ctrl+Alt+T)을 열고 제어판 저장소를 받습니다. 이미 받아 두었다면 두 번째 명령만 실행해 최신으로 맞춥니다.

git clone https://github.com/tjkoobro-netizen/omx-control-panel.git ~/omx-control-panel
cd ~/omx-control-panel && git pull

설치 실행

cd ~/omx-control-panel && bash install_control.sh

8단계가 차례로 진행됩니다. 이미 된 단계는 확인만 하고 넘어가므로, 중간에 멈췄다면 같은 명령을 다시 실행하면 됩니다. 질문이 나오면 대부분 Enter(기본값)로 충분합니다.

단계하는 일내가 할 일
1/8git, v4l-utils, python3.10 등 확인없으면 sudo 비밀번호 입력
2/8Tailscale 설치·로그인화면에 나온 주소를 브라우저로 열어 팀 계정으로 로그인
3/8GPU 노트북 선택, SSH 키 등록목록에서 team16-pc 번호 선택 → GPU 노트북 계정 이름 → 그 계정 비밀번호 한 번
4/8GPU 노트북의 내 계정에 학습·추론 서버 설치처음이면 Y. GPU 노트북 쪽 질문도 Enter로 진행
5/8LeRobot 환경(~/venv/il) 설치처음이면 Y. 20~40분 걸립니다(약 4GB)
6/8로봇 장치 이름(OMX 1·2·3)과 USB 권한sudo 비밀번호 입력
7/8제어판 설치, 설정 저장없음 (기존 설정은 백업 후 유지)
8/8바탕화면 아이콘 "OMX Control Panel"없음
마지막에 설치 완료 (v2.1.0)가 나오면 끝입니다.

한 번 로그아웃 후 다시 로그인

6단계에서 USB 직렬 포트 권한(dialout)을 새로 받았다면, 다시 로그인해야 적용됩니다. 설치 마지막에 안내가 나오면 꼭 해 주세요. 하지 않으면 점검에서 "포트를 열 수 없음"이 나옵니다.

로봇과 카메라 연결

팔로워·리더 모두 전원 어댑터를 연결하고 켠 뒤 USB를 꽂습니다. USB는 통신만 하므로 전원이 없으면 모터가 응답하지 않습니다. 로봇팔은 어느 포트에 꽂아도 자동으로 구분됩니다.

카메라는 PC 본체의 서로 다른 USB 포트에 나눠 꽂으세요. 우리 카메라는 켜질 때 USB 대역을 크게 잡습니다. 같은 허브나 같은 본체 포트에 카메라 2대를 몰면 한 대가 열리지 않습니다(화면에 0 fps). 허브를 쓰더라도 허브 하나에는 카메라 1대만 두세요. 같은 모델 카메라는 꽂은 포트로 구분하므로, 한 번 정한 뒤에는 포트를 바꾸지 마세요.
로봇팔로워리더
OMX 1/dev/omx_follower_1/dev/omx_leader_1
OMX 2/dev/omx_follower_2/dev/omx_leader_2
OMX 3/dev/omx_follower_3/dev/omx_leader_3

제어판 열기, 로봇 구성

바탕화면의 OMX Control Panel을 더블클릭합니다. 처음에는 아이콘을 우클릭해 실행 허용(Allow Launching)을 눌러야 할 수 있습니다. 터미널에서 omx-panel로 열어도 됩니다.

① 데이터 수집 탭 오른쪽의 로봇 구성 → [구성 바꾸기]에서 정합니다.

구성로봇 세트카메라 역할
단일 로봇
팔 1개		예: OMX 3front(필수), front_2(선택), wrist(필수)
협동 로봇
양팔을 한 로봇으로		왼팔 예: OMX 1
오른팔 예: OMX 2		front(필수), front_2(선택), wrist_left, wrist_right(필수)

카메라마다 미리보기를 눌러 화면을 보고 역할을 고르면 라벨(예: "OMX 2 · 왼팔 wrist")이 자동으로 붙습니다. [저장하고 점검]을 누르면 팔로워·리더 모터와 카메라를 모두 확인합니다.

점검 목록이 모두 초록이고, [카메라 켜기] 후 각 화면 오른쪽 위에 30 fps 근처가 나오면 준비 완료입니다.

첫 텔레옵

리더암을 팔로워와 비슷한 자세로 두고, 화면 맨 위 안전 확인란을 체크한 뒤 [텔레옵 시작]을 누릅니다. 팔로워가 출력 30%로 천천히 리더 자세까지 다가간 뒤 리더를 따라옵니다. 협동 로봇은 두 팔 모두 이렇게 시작합니다.

[중지]를 누르면 팔로워가 출력을 3초에 걸쳐 줄이고 토크를 끕니다(팔이 천천히 내려앉음).

처음 움직일 때는 팔 주변에서 손을 치우세요. 이상하게 움직이면 ① 탭의 [강제 종료](팔이 그 자리에 멈춤)를 누르고, 그래도 움직이면 팔로워 전원을 뽑으세요. 평가 중에는 [비상 정지] 한 번으로 제자리에 멈추고, 같은 버튼 [홈 위치로 이동]으로 천천히 돌아갑니다.

문제가 생기면

위쪽에 "GPU 노트북(omx-gpu)에 연결되지 않았습니다"

Tailscale이 꺼져 있거나 GPU 노트북이 꺼져 있습니다. 아래로 확인하세요. 응답이 오면 제어판을 새로고침합니다.

tailscale status && ssh omx-gpu echo ok
점검에서 "/dev/omx_follower_N 없음"

전원과 USB를 확인합니다. 그래도 없으면 연결된 장치 이름을 보고, 목록이 비어 있으면 관리자에게 그 로봇의 일련번호 등록을 요청하세요.

ls -l /dev/omx_*
"포트를 열 수 없음"

USB 권한(dialout)이 아직 적용되지 않았습니다. 로그아웃 후 다시 로그인하세요. 다른 프로그램이 같은 로봇을 쓰고 있어도 이렇게 나옵니다.

카메라 하나가 0 fps이거나 열리지 않음

USB 대역 부족입니다. 그 카메라를 PC 본체의 다른 포트(다른 허브)로 옮긴 뒤 로봇 구성에서 다시 지정하세요. 화면이 검으면(밝기 5 미만) 렌즈 덮개와 조명을 확인합니다.

아이콘을 눌러도 제어판이 열리지 않음

서버 기록의 마지막 줄을 확인해 관리자에게 보내 주세요.

tail -20 ~/il_ws/omx_logs/web.log
새 버전으로 업데이트하려면

저장소를 최신으로 받고 설치를 다시 실행합니다. 설정과 로봇 구성은 그대로 유지됩니다.

cd ~/omx-control-panel && git pull && bash install_control.sh
